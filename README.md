# DevCamp 2.0 — Spotify Website Clone (By Vishal)

A 3-page static Spotify-style website built with HTML and CSS only.

## Files
- index.html — Home
- browse.html — Browse all
- playlist.html — Playlist details
- style.css — shared external stylesheet

## Requirements covered
- Semantic header/nav/main/footer
- Form + required email input
- Images with alt text
- Anchor links between all 3 pages
- Track table
- External CSS
- Reused classes
- ID selector: #featured / #tracks
- Flexbox used throughout
- Box model: padding, margin, border-radius
- Palette: #1DB954 and #191414
- Hover effects
